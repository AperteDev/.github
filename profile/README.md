# Aperte

Open source apps for the Linux desktop, mostly GNOME, many of them keeping your data in your own Nextcloud.

## Projects

- [Notav](https://github.com/AperteDev/notav) - notes and a journal for GNOME, kept in your Nextcloud
- [Todav](https://github.com/AperteDev/todav) - tasks and calendar for GNOME, kept in your Nextcloud over CalDAV, with a GNOME Shell extension
- [Foldav](https://github.com/AperteDev/foldav) - a file manager for GNOME, made for the files in your Nextcloud over WebDAV
- [Gextant](https://github.com/AperteDev/gextant) - updates GNOME Shell extensions straight from their repositories, without waiting for extensions.gnome.org
- [Conflux](https://github.com/AperteDev/conflux) - background file-sync daemon syncing local directories to multiple remotes
- [Memeplex](https://github.com/AperteDev/memeplex) - meme browser, search and tagger
